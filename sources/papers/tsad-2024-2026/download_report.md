# TSAD Papers, 2024–2026: PDF Migration Report

## Scope and checks

- Organized **33 locally available conference papers**: 32 PDFs from the existing `TSAD_papers` folder and one 2026 KDD TSAD paper found under `AIOps_papers`.
- Searched the knowledge base, `/home/xieqitong`, and common temporary/download locations for the referenced summary Markdown and CSV. Neither source index was found. The original files therefore could not be copied, and their original download URLs cannot be recovered. The public links below are verified publisher/proceedings/preprint alternatives, not claims about the missing CSV values.
- No new PDF downloads were needed. Each of the 33 files was recognized as a PDF, had a `%PDF-` header and `%%EOF` trailer, exceeded 10 KB, and retained the same SHA-256 digest across migration. All 33 digests are unique; no duplicate paper was found in this set.
- Checked the text streams of all 33 PDFs against the report titles; every title's nontrivial words appear in its PDF. This is a title-text consistency check, not a claim that the unavailable source index was verified.
- The CCF column records the venue tier from the current CCF directory (7th edition, 2026). All collected venues are A or B. [CCF directory](https://www.ccf.org.cn/Academic_Evaluation/By_category/).
- PDF contents were not changed. Existing filenames were retained; the full bibliographic title is used in this report where a filename was truncated.
