# Concepts

这里保存从多篇论文、代码和资料中综合得到的概念知识。

Concept 不是单篇论文摘要，也不应把整篇论文内容复制到这里。每个 Concept 都会随着后续学习持续修订，文件顶部的 `Status: evolving` 表示它仍处于演化中。

## 知识更新规则

以后每阅读一篇论文、代码或资料，都需要检查：

1. 是否出现新的 Concept。
2. 是否需要补充已有 Concept。
3. 是否与已有资料存在关联。
4. 是否存在矛盾观点。
5. 是否产生新的问题。

更新时优先记录跨来源的共同机制、差异、适用条件、限制和自己的理解，并在相关笔记之间建立相对 Markdown 链接。
