## 方法关系与研究主题横向图

以下关系按“正常性参照、检测证据与证据边界”整理，不表示方法优劣或时间顺序。数据集、阈值与指标不统一，主表分数不可直接比较。

### 1. 正常性参照：prototype、memory、state adaptation 与统计动态

- [CAPMix](knowledge-dossiers/capmix.md) 用单一均值中心校正合成样本标签；[CrossAD](knowledge-dossiers/crossad.md) 用跨尺度原型；[Graph-MoE](knowledge-dossiers/graph-moe.md) 用图专家和 latent memory；[TeamWork](knowledge-dossiers/teamwork.md) 按通道角色分支。它们压缩或组织正常表示的对象不同，均不自动对应真实业务状态标签。
- [MACE](knowledge-dossiers/mace.md) 以服务级 Fourier bases 表示频谱差异；[When Model Meets New Normals](knowledge-dossiers/when-model-meets-new-normals.md) 在测试流中适配趋势和预测正常区域；[IMPACT](knowledge-dossiers/impact.md) 针对污染监督与开放集；[TimeRCD](knowledge-dossiers/time-rcd.md) 和 [VLM4TS](knowledge-dossiers/vlm4ts.md) 以同序列 context 作相对参照。
- [COGNOS](knowledge-dossiers/cognos.md) 的 residual white-noise null 与 [Conditional Normalizing Flows](knowledge-dossiers/cnf-latent-dynamics.md) 的 latent dynamic law 显式陈述统计假设。它们提升可检验性，但假设被拒绝本身不判定业务原因。

### 2. 关系与结构证据：从变量预测关系到时间关联

- [CAROTS](knowledge-dossiers/carots.md) 将 Granger 预测关系用于因果保持 / 破坏增强；[GCAD](knowledge-dossiers/gcad.md) 以梯度构造 predictive-influence proxy；[OracleAD](knowledge-dossiers/oraclead.md) 结合点残差与结构偏差。
- [SARAD](knowledge-dossiers/sarad.md) 比较前后半窗空间关联，[CCM-TAD](knowledge-dossiers/ccm-tad.md) 用 channel profile cluster 和 causal temporal mask，[Graph-MoE](knowledge-dossiers/graph-moe.md) 动态路由图专家，[TeamWork](knowledge-dossiers/teamwork.md) 用 ERI 统计角色，[ScatterAD](knowledge-dossiers/scatterad.md) 建模时间戳滞后图。
- 这些工作共享“关系变化可作为异常证据”，但图节点、关系估计和因果语义不相同。除非与 topology、Trace 或 intervention ground truth 对齐，不把它们的 graph / causal / dominant 名称解释为已验证的服务根因。

### 3. 时域、频域、曲率、残差与多视角融合

- [MACE](knowledge-dossiers/mace.md)、[TFMAE](knowledge-dossiers/tfmae.md)、[TriAD](knowledge-dossiers/triad.md) 与 [TFC](knowledge-dossiers/tfc.md) 分别用服务频率基、时频 masked views、temporal-frequency-residual 三域和 temporal-frequency-curvature 证据。
- [FlowFuse](knowledge-dossiers/flowfuse.md) 把 temporal/frequency × clustering/reconstruction 四路分数交给 coupling flow 建模；[COGNOS](knowledge-dossiers/cognos.md) 处理 reconstruction residual 的统计结构；[AnoMamba](knowledge-dossiers/anomamba.md) 通过 global step-size reweighting 改变重建依赖；[IGAD](knowledge-dossiers/idempotent-reconstruction.md) 约束重建映射。
- 多视角消融说明各 view 在特定 benchmark 中可互补；仍需控制不同 view 共同失效、状态变化造成多路同步偏移和线上 threshold 的影响。

### 4. 噪声、污染、合成异常和认证鲁棒

- [CAPMix](knowledge-dossiers/capmix.md) 处理合成异常可信度与污染训练；[IMPACT](knowledge-dossiers/impact.md) 处理少量标签及 open-set contamination；[PCRTA](knowledge-dossiers/pcrta.md) 以扰动引导对比学习。
- [Fortifying Time Series](knowledge-dossiers/fortifying-time-series.md) 对特定 DTW perturbation 给出随机平滑证书；[KAN-AD](knowledge-dossiers/kan-ad.md) 用平滑 Fourier 预测；[IGAD](knowledge-dossiers/idempotent-reconstruction.md) 收紧重建目标区域；[COGNOS](knowledge-dossiers/cognos.md) 建模残差噪声并做 Kalman smoothing。
- 鲁棒性结论只适用于各自威胁模型与扰动协议。证书不保证原预测正确，合成扰动不保证覆盖真实故障，低通或平滑也可能抹掉局部故障。

### 5. 评测协议和 benchmark 不是模型机制的替代

- [Quo Vadis](knowledge-dossiers/quo-vadis.md) 比较简单 baseline、score normalization、point / range metrics 和阈值协议；[TSB-AD](knowledge-dossiers/tsb-ad.md) 统一整理数据、指标和 detector 比较。
- 它们的作用是校正研究比较方式，不等于证明某一类模型普遍充分。跨论文排序必须同时注明点调整、阈值是否用测试标签、事件边界口径、随机种子和数据划分。

### 6. LLM / VLM：teacher、提示、推理轨迹与视觉核验

- [AnomalyLLM](knowledge-dossiers/anomalyllm.md) 以冻结 LLM 表征作为 teacher；[Delving into LLMs for TSAD](knowledge-dossiers/delving-llm-tsad.md) 设计 index-aware 数值 / 图像提示；[AnomSeer](knowledge-dossiers/anomseer.md) 生成类别、区间和 reasoning trace；[VLM4TS](knowledge-dossiers/vlm4ts.md) 先做 patch matching proposal 再做整体视觉核验。
- [TimeRCD](knowledge-dossiers/time-rcd.md) 属 synthetic relative-context foundation model，目标是时间 / 跨变量关系偏差，并非将生产文本上下文直接输入通用检测器。
- 现有 benchmark 结果可以支持特定输入形式下的检测表现；不能单独支持 reasoning fidelity、真实 root cause、生产 Trace / release 上下文安全性或推理成本可接受。

### 7. 生产场景覆盖与证据层级

- [CAPMix](knowledge-dossiers/capmix.md) 包含 Kuaishou KAIOps 案例；[MACE](knowledge-dossiers/mace.md) 使用云服务 / 多实体监控数据。它们提供较直接的运维场景证据。
- 其余大量工作主要在公开 benchmark、合成因果数据、UCR 或转换后的数值序列上比较。benchmark 数据来自工业领域，并不等于线上部署证据。
- 全集合最稳定的综合判断是：异常检测依据已从 reconstruction / prediction error 扩展到表示距离、频谱、关系、统计检验、开放集影响和模型视角分歧；这些证据的业务来源解释仍需独立的外生 context 与 incident ground truth。
