## Reading / evidence rule

Each dossier distinguishes author statements, experiments, and knowledge-base analysis. It cites the source paper by PDF section, page, equation, figure, or table. The six dossiers cover TraceLLM, LLM-AP, Synthetic Time Series for Anomaly Detection in Cloud Microservices, GenIAS, MODIFy, and AIOpsLab.

AMulSys is not represented as a completed dossier: the verified publisher route requires purchase and direct PDF access returned 403. Its exact metadata and pending status are recorded in the download report. No method claim is inferred from its abstract.

The set contains different task types: structured Trace generation, numeric sequence augmentation, runtime fault injection, multimodal diagnosis, and Agent evaluation. Do not treat a positive result in one category as evidence for another.
